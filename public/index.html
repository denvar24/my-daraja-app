Safaricom Daraja API Integration

Introduction

The Safaricom Daraja API acts as an integration gateway bridging modern application backends directly to Safaricom's financial infrastructure. By facilitating programmatic access to M-PESA payment tools, developers can construct automated payment workflows natively within web applications.

How to Integrate and Use the API

Integrating Daraja's M-PESA Express (STK Push) involves a structured multi-stage HTTP handshake:

  1. Authentication: Using Basic Auth with a client key and secret, the developer sends a request to the Daraja OAuth endpoint to acquire a temporary Bearer access token.
  2. Request Construction: An STK Push request payload is created containing the donor's phone number, amount, business shortcode, timestamp, and a base64-encoded security password.
  3. Prompt Dispatch: The payload is dispatched via HTTP POST to the STK Push endpoint. Safaricom's server processes this and forces a SIM Toolkit prompt directly onto the user's mobile screen, requesting their M-PESA PIN.
  4. Asynchronous Callback Resolution: Once the user confirms or declines the PIN prompt, Safaricom posts an asynchronous JSON payload to the developer's registered HTTPS Callback URL to record transaction status.

Key Benefits of Daraja API for Web Fundraising

  • Frictionless UX: Eliminates manual entry of PayBill numbers and account references, drastically reducing drop-off rates during payment checkout.
  • Real-Time Verification: System callback handlers immediately update order states or fundraising counters without manual verification of SMS receipts.
  • High Security: M-PESA PIN entry occurs natively within the encrypted SIM environment, meaning web applications never handle sensitive financial secrets directly.
  • Scalability: Built to process high volumes of concurrent transactions automatically, ideal for large-scale donor drives.
